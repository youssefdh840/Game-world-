## 🌟 نظرة عامة (Overview)

**World Challenge** هي لعبة ويب تفاعلية للهواتف المحمولة والحواسيب تجمع بين التنافسية الثقافية والتعارف العالمي:
- **العب (Play):** تنافس رأساً برأس (1 ضد 1) عبر نظام المطابقة التلقائي السريع أو في غرف خاصة مع أصدقائك عبر رمز الغرفة (Room Code) المكون من 6 خانات.
- **تعرّف (Connect):** التقي بلاعبين من أكثر من 25 دولة مختلفة (تونس 🇹🇳، اليابان 🇯🇵، فرنسا 🇫🇷، البرازيل 🇧🇷، مصر 🇪🇬، كوريا الجنوبية 🇰🇷، وغيرها الكثير).
- **استكشف (Explore):** اختبر معلوماتك العامة، سرعة بديهتك، قوة ذاكرتك، ومهاراتك المنطقية لجمع أختام الدول في جواز سفرك.

| اللعبة | الرمز | نمط اللعب | تفاصيل التحدي |
| :--- | :---: | :---: | :--- |
| **Country Quiz**<br>*(أسئلة وأعلام الدول)* | 🌍 | 5 جولات<br>+250 XP | • مسابقة مصورة لاختبار المعرفة بأعلام الدول، العواصم العالمية، والمعالم التراثية.<br>• اختيار 5 أسئلة فريدة عشوائياً لكل مباراة دون أي تكرار.<br>• تلميحات العاصمة الصحيحة ومكافآت السرعة للإجابة الخاطفة. |
| **Guess the Number**<br>*(تخمين الأرقام والمنطق)* | 🔢 | 3 جولات<br>+180 XP | • تنافس منطقي لاكتشاف الرقم السري المستهدف (من 1 إلى 100) بأقل عدد ممكن من المحاولات قبل الخصم.<br>• إشارات ذكية فورية: أعلى (High ⬆️) أو أقل (Low ⬇️).<br>• نظام تفاعلي من 6 محاولات كحد أقصى لكل جولة. |

## ✨ المميزات الرئيسية (Key Features)

1. **المزامنة واللعب التنافسي المباشر (Real-Time Multiplayer):**
   - إنشاء غرف خاصة بالرمز (Room Code مثل `GAXF6L`) أو الانضمام السريع.
   - بحث تلقائي سريع عن خصم متاح عبر خوادم Firestore.
   - مزامنة فورية لحركات ونتائج اللاعبين وإظهار تقدم كل طرف بدقة وسلاسة.
   - انتقال فوري وتلقائي للجولة التالية عند إجابة كلا اللاعبين.

2. **تسجيل الدخول الدائم والضيوف (Authentication & Persistence):**
   - تسجيل الدخول بحساب **Google** بنقرة واحدة، مع تثبيت الجلسة محلياً (`browserLocalPersistence`) لمنع تسجيل الخروج التلقائي عند إغلاق أو تحديث المتصفح.
   - اللعب الفوري كضيف (**Guest Play**) مع تحديد الاسم ودولة اللاعب وعلمها.
   - إمكانية التسجيل بالبريد الإلكتروني وكلمة المرور.

3. **الدردشة التفاعلية والمشاعر (In-Game Live Chat):**
   - شات لحظي مدمج داخل شاشة اللعب مع دعم التعبيرات السريعة والإيموجي الثقافية.
   - حماية وأمان مع أدوات كتم الصوت والإبلاغ عن السلوك غير اللائق.

4. **المؤثرات الصوتية والاحتفالية (Sound & Audio FX):**
   - مؤثرات صوتية تفاعلية مبنية بواسطة **Web Audio API** (نقرات الأزرار، الإجابات الصحيحة/الخاطئة، صوت ختم الجواز، وألحان الانتصار).
   - احتفالات القصاصات الملونة (Confetti) عند حسم الجولات والفوز بالمباراة.

5. **لوحة الصدارة والمهام اليومية (Leaderboards & Quests):**
   - تصنيف اللاعبين عالمياً، أسبوعياً، ومحلياً حسب الدولة.
   - مهام يومية متجددة تكافئ اللاعبين بنقاط الخبرة (XP) وسلاسل النشاط اليومي (Daily Streaks).

## 🛂 نظام جواز السفر والأوسمة (Virtual Passport & Badges)

- **جواز السفر الافتراضي (Digital Passport Booklet):**
  - في كل مرة تواجه فيها لاعباً من دولة جديدة وتنهي المباراة، يُطبع ختم وتأشيرة تلك الدولة رسمياً في جواز سفرك مع تاريخ المواجهة وعلم الدولة.
- **مستويات الخبرة (XP & Levels):**
  - تدرج مستمر من "مسافر مبتدئ" إلى "مستكشف عالمي"، مع شريط تقدم بصري.
- **نظام الأوسمة والإنجازات (Badges):**
  - 🏅 *First Journey* — أول مباراة ورحلة مكتملة.
  - 🗺️ *World Traveler* — مواجهة لاعبين من 5 دول مختلفة.
  - 👑 *Global Master* — تحقيق الفوز في 10 مباريات متتالية.
  - ⚡ *Lightning Reflexes* — الإجابة الصحيحة بأسرع توقيت قياسي.

## ⚡ المزامنة اللحظية والشبكة (Realtime Sync & Networking)

تعتمد اللعبة على معمارية هجينة وموثوقة لضمان استمرار اللعب دون أي بطء أو انقطاع:
1. **قاعدة بيانات Firestore اللحظية (Primary Cloud Sync):**
   - الاستماع الفوري عبر دالة `onSnapshot` للتغيرات الطارئة على وثائق الغرفة (`gameRooms`).
   - حفظ النتائج وحالة اللاعبين وردودهم بشكل آني وموثوق.
2. **بروتوكول PeerJS / WebRTC (High-Speed Fallback):**
   - قناة اتصال مباشر P2P لتبادل إشارات الإجابة السريعة في حال تقلبات الشبكة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **الواجهة الأمامية (Frontend):**
  - [React 19](https://react.dev/) — بيئة العمل لبناء واجهات تفاعلية فائقة السرعة
  - [TypeScript](https://www.typescriptlang.org/) — دقة وأمان فحص الأنماط البرمجية
  - [Tailwind CSS v4](https://tailwindcss.com/) — تنسيق متجاوب حديث وعصري للهواتف والشاشات الكبيرة
  - [Lucide Icons](https://lucide.dev/) — حزمة أيقونات متناسقة وخفيفة
  - [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti) — مؤثرات بصرية احتفالية
- **الخدمات السحابية وقاعدة البيانات (Backend & Cloud):**
  - **Firebase Firestore** — قاعدة بيانات سحابية لحظية لإدارة الغرف والجلسات
  - **Firebase Authentication** — إدارة هويات المستخدمين مع بقاء الجلسة مفعلة
- **الصوتيات والشبكات (Audio & Networking):**
  - **Web Audio API** — توليد نغمات ومؤثرات صوتية نقية دون الحاجة لتحميل ملفات mp3 ضخمة
  - **PeerJS** — اتصال P2P متزامن للمباريات التنافسية

## 🚀 التشغيل والتثبيت محلياً (Setup & Installation)

### المتطلبات المسبقة:
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- مدير الحزم `npm`

### خطوات التشغيل:
1. **الانتقال لمجلد المشروع:**
   ```bash
   cd world-challenge
   ```

2. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

3. **بدء خادم التطوير المحلي:**
   ```bash
   npm run dev
   ```
   *يفتح التطبيق على المنفذ `http://localhost:3000`.*

4. **بناء المشروع للإنتاج (Production Build):**
   ```bash
   npm run build
   ```

5. **التحقق من صحة الأنماط والشيفرة (Lint):**
   ```bash
   npm run lint
   ```

## 🔒 قواعد الأمان والبيانات (Security & Firestore)

تخضع اللعبة لقواعد أمان وحماية صارمة في `firestore.rules`:
- عزل بيانات المستخدمين الشخصية بحيث لا يملك صلاحية تعديلها إلا صاحب الحساب نفسه.
- التحقق من صلاحيات الانضمام والتعديل على وثائق مباريات `gameRooms` لضمان نزاهة النتائج ومنع التلاعب.
- صلاحيات قراءة عامة للوحات الصدارة المفتوحة للمتنافسين.
